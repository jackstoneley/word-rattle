Topple

Tip the block end over end. Drop it in the hole.

Levels

How to play
  • Swipe on the board, or use the arrows, to tip the block over. It rolls end over end, so it is sometimes standing up and sometimes lying down.
  • Get the block standing up on the dark hole to finish the level.
  • Don't let any part of it hang over the edge. If it falls, it pops back to where it was.
  • Orange tiles are fragile: they hold the block lying down, but not standing up.
  • Round switches work when any part of the block touches them. ✕ switches only work when the block stands on them. Each one opens or closes the matching bridge.
  • Each level has a par: the fewest moves it can be done in. Match it for three stars.
  • Undo takes back a move. Hint shows the best next move, but the level then gives at most two stars.
